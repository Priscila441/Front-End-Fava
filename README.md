# Angular E-commerce Project

This is an e-commerce project built with **Angular 20**, where users can:
- Browse a list of products  
- See product details  
- Add items to the cart  
- Edit the cart  
- Generate orders  
- Use a login system  

For admins, CRUD operations are available for managing products.

---

## ⚠️ Project status
The application is **not finished yet**, so some features are still under development.

### Features not working yet:
- Filters by categories  
- Order history  
- Order tracking  
- CRUD for categories, users, and orders  

---

## 🛠️ Technical details
- **Angular 20** with **TypeScript**
- **Angular Material** and **CDK** for UI components  
- **TailwindCSS** and **Flowbite** for styling  
- **RxJS** for reactive programming  
- **Zone.js** for change detection  
- **JWT Decode** for authentication  
- Built and tested with **Karma** + **Jasmine**
